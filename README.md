# 离线本地销售数据智能分析 Agent (SalesDataTool)

一个面向业务数据分析师的 **AI Agent 产品**，将复杂桌面工具的高频操作封装为自然语言驱动的工作流。基于原有 QT 桌面业务工具，通过 **零侵入封装 + RAG 知识库 + 本地轻量化大模型**，实现“一句话完成数据导入 → 公式计算 → 报表导出”全流程，高频任务操作步骤从 12 步缩减为 1 句指令，且全程数据不出设备。

## 🎯 产品定位

| 维度 | 描述 |
|------|------|
| **目标用户** | 业务数据分析师、销售运营人员 |
| **核心价值** | 降低复杂工具的使用门槛，保障敏感业务数据安全 |
| **产品形态** | RAG 知识库 + 工具集封装 + 本地离线大模型驱动（存量代码零侵入） |
| **技术底座** | 原生 QT 桌面工具（三层架构 + 逆波兰表达式引擎 + MySQL 持久化） |

## 🧠 产品设计思路

### 用户痛点

原有 QT 桌面工具功能强大但操作路径深，完成一次高频销售统计需手动点击 12 步菜单；同时业务数据高度敏感，严禁上传公网。

### 产品决策

1. **零侵入封装**：对原有三层架构代码不做任何修改，仅将数据导入、公式计算、数据库持久化、报表导出封装为 Agent 可调度的工具集。
2. **知识库构建**：基于三层架构文档及 17 类高频统计场景最佳实践，搭建专属 RAG 知识库。
3. **全离线推理**：为满足数据安全合规要求，集成轻量化本地大模型，确保业务数据“不出设备”。
4. **自然语言驱动**：将“数据导入 → 公式计算 → 报表导出”全流程封装为自然语言指令驱动，用户无需记忆复杂菜单路径。

### 产品价值量化

| 指标 | 优化前 | 优化后 | 提升幅度 |
|------|--------|--------|----------|
| 高频任务操作步骤 | 12 步 | 1 句指令 | **92%+** |
| 用户操作效率 | 基准 | 提升 75% | **75%** |
| 原有代码复用率 | — | 100% | **零稳定性风险** |
| 数据安全 | 需联网 | 全离线 | ✅ 数据不出设备 |

## 🚀 快速体验

### 环境要求

- Windows 10 / 11
- Visual Studio 2022
- Qt 6.9.3 + Qt VS Tools
- MySQL 8.0 + MySQL ODBC Connector

### 编译运行

```bash
git clone https://github.com/zheng-j-q/SalesDataTool.git
cd SalesDataTool
# 用 Visual Studio 打开 .sln 文件
# 确保 Qt 模块包含: core;gui;widgets;sql
# 点击"本地 Windows 调试器"运行
```

### ODBC 数据源配置

1、打开 ODBC 数据源管理器（64 位）

2、添加 系统 DSN → 选择 MySQL ODBC 8.0 Unicode Driver

3、Data Source Name: MySQLSales

4、Server: localhost，Port: 3306

5、User: root，Password: 123456

### 使用流程

1. **加载数据**：点击按钮，选择 CSV 文件
2. **统计分析**：查看按产品汇总和总销售额
3. **保存到数据库**：将当前数据持久化到 MySQL
4. **计算表达式**：在输入框中输入逆波兰表达式（如 `3 4 + 3 *`），点击计算
5. **导出报表**：将数据导出为 CSV 文件
